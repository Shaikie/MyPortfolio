# MyPortfolio

A dark editorial personal developer portfolio built with React, TypeScript, Vite, Tailwind CSS, Wouter, Lucide, and Framer Motion-ready primitives from the managed frontend foundation.

## Current direction

The interface follows the **Graphite Field Notes** system: graphite surfaces, warm Workbench Saffron signals, editorial offsets, ruled metadata, and candid verification states. It is intentionally structured so personal information can be added without rewriting the UI.

## Local development

```bash
pnpm install
pnpm dev
```

Run `pnpm check` for TypeScript validation and `pnpm build` for a production build.

## Content still required

The repository currently contains no personal biography, CV, verified skills, project case-study notes, email address, LinkedIn URL, or screenshots. Those fields are represented as explicit placeholders rather than invented claims. The public GitHub source link is the only verified external link currently included.
